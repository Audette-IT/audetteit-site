**Why build on Cloudflare:** checked in Cloudflare's docs on 2026-09-25.
Workers, D1 and SQLite-backed Durable Objects are all on the free plan (D1
has daily row read/write limits; since 2026-09-01 exceeding them pauses
queries until midnight UTC, data is kept). Access is free up to 50 users.
Email stays on Google Workspace via the Gmail API, so MX never changes.

### A request

- From (name, email), what's going on, source (`form`/`email`/`chat`)
- Michael's private notes, the quote (visible only to Michael and that
  customer, never on a public page), and the message thread
- **Status** in plain words customers see: **New → Quoted → Scheduled →
  Working on it → Done**, plus **Closed** (no reply, or they said no)
- Customers never see ticket numbers; wording is "request", never "ticket".
  Add fields (devices, room, …) only once real use asks for them.

## 5. Design

- **The `audette-it-design` skill is the design system.** Read its
  `SKILL.md`, then `references/apps.md` (app UI: panels, data tables, status
  as word + shape, stats, alerts, side nav, dialog) and `references/voice.md`.
  Start pages from `assets/templates/standalone-page.html` (no GTM) with
  `assets/room-guide.css` + `assets/app-extras.css`.

  Done = filled ink dot, In progress-type states = hollow blue dot,
  "Needs you" = yellow pill, broken = error diamond, unknown = hollow grey.
- Copy is Michael's voice: first person, casual, short sentences, no hype.
  Errors say what happened and what to do ("Add a valid email so I can reply.").
- Check work with `python3 .claude/skills/audette-it-design/scripts/check_design.py <files>`.
- **Draft 2–3 options as Artifacts before building any new screen.** On the
  site, building a draft in full before approval was wasted work.

## 6. Security

- Strict CSP like the site: `script-src 'self'` (no inline scripts, all JS in
  external files), `frame-ancestors 'none'`, nosniff, `X-Frame-Options: DENY`,
  Referrer-Policy, Permissions-Policy, HSTS (no `includeSubDomains`, to match
  the site). Turnstile needs `challenges.cloudflare.com` in script-src/frame-src.
- Agent routes sit behind Cloudflare Access; also verify the Access JWT
  (`Cf-Access-Jwt-Assertion`) in the Worker, don't trust the path alone.
- Customer private links: long random tokens (≥128 bits), stored hashed,
  revocable. Email sign-in links: one-time, short expiry.
- Secrets (Gmail OAuth client/refresh token, Turnstile secret) only as
  Worker secrets (`wrangler secret put`), never in the repo.
- Rate-limit the public form and chat endpoints.

## 8. Workflow

- `feature/*` (optional) → `dev` → `staging` → release PR → `main`.
  Workers Builds (Cloudflare) builds every push; `main` is production.
- **Release:** `git checkout -B release/<name> origin/staging`, restore
  `main`'s README, create the PR, **then** write its number into this file,
  merge with `mcp__github__merge_pull_request` (pass `expectedHeadSha`),
  watch the "Workers Builds" check run, verify live, sync `dev`/`staging`
  back from `main` (keep each branch's README).
- Don't burst branch pushes right before a release: Workers Builds runs one
  build at a time and previews queue ahead of production.
- **Before every push:** typecheck, tests, `wrangler deploy --dry-run`,
  and the design checker on changed pages. CI (GitHub Actions) is blocked for
  this account (site issue #32), so local checks are the only gate.
- Always `git fetch` and work from `origin/<branch>`; local copies go stale.

## 9. Session environment (learned on the site repo)

- **Repo creation via the GitHub connector returns 403** in this org; the
  owner creates repos by hand. Branch deletes also return 403.
- `gh` isn't available; use the GitHub MCP tools. `GITHUB_TOKEN` works for
  REST reads; fetch issues one by one (the list endpoint returns ~3) and
  always fetch `/issues/N/comments` (the count reads 0).
- Sessions can't reach `*.audetteit.com` directly; use Firecrawl
  (`maxAge: 0`) for live checks and `https://dns.google/resolve?...` via
  Firecrawl for DNS lookups.
- Google Fonts is blocked in sessions: screenshots use fallback fonts. For
  rendered images use `@fontsource/red-hat-display`/`-text` from npm.
- Playwright + Chromium are pre-installed; never run `playwright install`.
- Don't put `pkill -f wrangler` in the same shell that started it (it kills
  its own shell, exit 144); kill by PID in a separate call.
- The scratchpad is wiped between sessions; keep reusable scripts in `tools/`.
- A session can't end a turn with uncommitted changes; park unfinished work
  on `wip/...`.

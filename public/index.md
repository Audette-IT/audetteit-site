## Process: the same four stages, every time

Whether it's setting something up for the first time or fixing something that broke tonight.

1. **Assess** — Figure out what's actually going on before changing anything.
2. **Deploy** — Roll out the fix or setup in a way that doesn't break what's already working.
3. **Monitor** — Keep an eye on it afterward instead of disappearing once it's "done."
4. **Respond** — If it acts up again, it gets triaged and fixed — same process, no starting over.
